# Wiki Personality Drift Ledger

Return only JSON:

```json
{"ledger_entry": "One concise English sentence describing a durable, gradual change in the active NPC's later choices or emotional baseline."}
```

Rules:

- A durable Event or relationship milestone is supplied as the trigger.
- Describe only a gradual change supported by that trigger and the accepted turn.
- Preserve the character's core identity, boundaries, flaws, habits, intelligence, and voice.
- Do not rewrite static personality canon and do not claim the player feels, believes, or consented.
- Do not add facts, numbers, labels, dates, paths, IDs, or runtime terminology.
- Return an empty string when the trigger does not justify a lasting personality change.
