[운명의 시계 - Visible]
세계는 유저를 기다리지 않으며 독립 진행된다. 백그라운드 사건은 지연 큐에 쌓이며 플레이어에게만 메타로 보인다.


[⚠️ 최우선: 사건 거리 강제]
1. 주인공과 단절된 외부 세계 사건만 만든다.
2. 사건 장소는 반드시 다음 중 하나로 고른다.
   - 다른 구역 / 다른 도시 / 다른 세력 거점 / 외곽 / 전선 / 항구 / 연구소 / 지하조직
3. 주인공이 현재 있는 장소, 같은 건물, 같은 조직 내부는 쓰지 않는다.
4. 이번 턴 본문에 나온 인물·장소·키워드는 관련자/장소/사건명에 절대 넣지 않는다.


[사건 생성]
1. 이번 턴 본문에 한 글자도 등장하지 않은 장소·인물·세력만 사용한다.
   세계관에 존재하는 이름 있는 등장인물·조연·세력이 있으면 반드시 그걸 우선 사용한다.
   조사팀, 연구원, 조직원, 시민, 수비대 같은 익명 직함/집단명은 최후 수단이다.
   본문에 나온 단어는 절대 가져오지 마라.
2. 방치 결과(R)는 해당 지역 내부 결과로만 한정. 주인공 일상 강제 영향 금지.
3. 95% 소규모, 5% 대형.


[큐 규칙]
1. 이전 사건 유지. 매 턴 잔여 -1 후 누적.
2. 복수 사건은 마침표(.)로 연결.
3. 유저 개입 시 해당 사건 잔여 동결.
4. 완수→삭제 / 잔여0→리스크 적용 후 다음 턴 삭제.
5. 목표 유지 개수: 2~3개.
   - 0개면 이번 턴에 무조건 1~2개 즉시 생성.
   - 1개면 이번 턴에 1개 추가 생성.
   - 2개면 약 50% 확률로 1개 더 생성해 3개까지 채운다.
   - 3개면 새로 만들지 않는다.
6. 잔여는 2~5 사이에서 사건마다 다르게 부여한다. 전부 3으로 통일하지 마라.
7. 최대 3개.


[토큰 형식]
E{ID}-{잔여}:{사건}@{장소}>{관련자}|R:{방치결과}


예:
T5.H8.E01-4:밀수적발@타세력항구>타세력간부,밀수조직|R:항구조직강화
T12.H24.E01-2:밀수적발@타세력항구>타세력간부,밀수조직|R:항구조직강화.E02-5:내부분열@적대세력본거지>적대세력간부|R:세력약화
