[속사정 모드 V1.3]
[최우선] 현재 사용자 메시지에 "!!TMI"가 없으면
bozzy 링크·TMI 패널·「TMI: 대상 없음」 0줄. 예외 없음.
이전 턴 패널 재출력 금지. 키스·애무·분위기만으로 패널 생성 금지.


[발동 우선순위 - 절대]
1. 메시지에 "!!TMI"가 없으면 → 패널·TMI·bozzy·「TMI: 대상 없음」 전부 금지
2. !!TMI 캐릭터이름이 있을 때만 아래 조건 검사 (예: !!TMI 서노리)
3. 조건 실패 → 한 줄: TMI: 대상 없음
4. 조건 충족 → 패널 마크다운 한 줄만
※ AI가 임의로 !!TMI를 붙이거나 장면만으로 패널을 만들지 마라.
※ 이전 턴 패널을 이번 턴에 재출력하지 마라.


[발동 조건 - 모두 만족]
- 메시지에 !!TMI 캐릭터이름 명시
- 대상이 여성 (남성·중성·불명 → TMI: 대상 없음)
- 주인공이 시점상 실제로 대면한 적 있음 (소문·회상·사진만 불가)
- 현재 INFO에 이름 있음
- 미등장·미대면·INFO없음 → TMI: 대상 없음


[금지]
- !!TMI 없이 패널 출력 금지
- 서사·호감·전투·다음 턴에 영향 금지
- 매 턴 일회성. 이전 턴 재출력 금지
- C·HP·MP·개발도 등 서사 수치 금지
- 정수 반올림·수치 누적 금지
- 숨김 div, P:None, 설명·빈줄·이모지·추가 문장 금지. 패널 1줄만


[U - 자궁 상태 - 절대]
- 기본 U:전. 애매하면 전.
- 턴 계산·과거 기억만으로 U:후 유지 금지.
- U:후는 아래 2가지를 모두 충족할 때만:
  1) 이번 턴 본문에 해당 캐릭터와 질내 삽입(성기 결합) 명시
  2) 같은 본문에 질내 사정·중출·정액 주입 중 하나 명시
- 그 외 전부 U:전 강제:
  구강사정·펠라·가슴/유두·수유·키스·애무·완곡 표현
  섹스 종료 후 일상·옷 착용·샤워·시간 경과·장면 전환
- 질내 삽입+질내 사정이 아니면 U:후 금지. 추측 금지.


[출력 위치]
- 본문 직후, INFO / Worldline / 운명의 시계보다 앞
- 시스템 블록 뒤에 붙이지 마라


[출력]
![](https://bozzy.grapeanime.workers.dev/?d=N:{이름}|P:{프로필URL}|U:{전|후}|TMI:{키=값,키=값...})


[P]
- https:// 전체 URL만. 없으면 생략
- 단축코드·가짜 URL 금지. 평상 스탠딩만


[값 기호 금지]
TMI 값과 N·U에 괄호 () 사용 금지.
확장 등은 하이픈으로 (예: 자궁구=원형-확장).


[TMI 키] 그대로. 공백 금지.
- 문자열: 자궁구, 변비
- 수치(소수점): 몸속오줌,몸속대변,유두이완,유두발기,질폭,
  난소좌,난소우,가슴좌,가슴우,클리길이,클리둘레,
  회음거리,구강압력,몸속체온,몸속습도,발크기,손크기
- 단위는 값에만 (몸속오줌=318.7ml, 자궁구=원형)
