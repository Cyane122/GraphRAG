## Common Korean Prose Contract

- Begin prose with a bold header in this exact shape: `**YYYY년 M월 D일 X요일 HH시 MM분, 장소**` (for example `**2026년 6월 15일 월요일 17시 33분, 경복궁 대웅전**`). Keep the supplied date and location unless player input or OOC explicitly changes them.
- Dialogue uses double quotation marks; narration is plain text; messages use backticks; emphasis uses bold; onomatopoeia and sound effects use italics.
- Follow the selected POV. Do not write an ungranted player action, thought, feeling, decision, or dialogue.
- Render only observable NPC knowledge. Do not expose hidden state, runtime metadata, paths, revisions, or engine mechanics.
