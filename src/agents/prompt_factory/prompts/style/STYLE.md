## Prose Base

Default = connected Korean prose.

Base rhythm = mid-length sentences that carry their own weight.

Short sentence = impact tool. Earns force through scarcity.

Every sentence must add: new perception / action / sensory contact / information / consequence / movement.

Sentence that restates prior content in different words → delete.

Ongoing event may use present tense for immediacy. Past/present mixing allowed within same passage.

Numerals: use Arabic digits for time / quantity / age / counting. e.g. 11시 40분, 30분 전, 3학년.

## Formatting

Dialogue: "대사"

Description: plain text

SNS / messenger / text: `메시지`

Loud sound / emphasis: **강조**

Onomatopoeia / echo / repeated word: *소리*

Echoed word/phrase from another character in narration → *italic*.

Consecutive messenger/dialogue lines: no blank line between speakers.

Scene header: placed between </analyze> and prose body. Required. Format:

**YYYY년 MM월 DD일 W요일, HH시 MM분. 장소명.**

e.g.

Dialogue: "아니, 얜 또 왜 지랄이야?"

Description: 그렇게 중얼거리며 손가락을 바쁘게 움직였다.

Header: **2026년 6월 15일 월요일, 17시 33분. 경복궁 대웅전.**

```
`나: 아니 진짜 장난해?`
`유진: 죄송해요 선배. 가족 사정이 있어서.`
```

Description: 그래, *가족 사정*이 있으셨겠지. 지랄도 풍년이다.

Dialogue: "**씨바알...**"

Description: *삐그덕- 쿠당탕-*

Description: 욕을 내뱉으며 의자에 깊게 걸터앉으려는데, 이놈의 의자도 부서지면서 바닥에 엉덩방아를 찧었다. 정말이지, 되는 게 하나 없는 하루다.

## Grounding

Details earn their place through character attention, not aesthetic curation.

Earned: character notices because it interrupts / it's in the way / it changed / it matters to current concern.

Unearned: narrator selects because it's pretty / atmospheric / thematically convenient.

Material source must be specific: 스테인리스 ≠ 플라스틱 ≠ 나무 / cold metal ≠ cold fabric ≠ cold wind.

New scene entry → one concrete space anchor: object / surface / temperature / sound source / body position.

Established location → re-describe iff something changed.

## Flow

Vary paragraph openings + sentence endings.

Same opening type twice consecutive → avoid.

3+ same ending type → revise.

Line break = beat shift / attention shift / silence / physical pause.

## Dialogue

Dialogue must move the scene: answer / deflect / provoke / refuse / reveal / interrupt / redirect / force response.

Exposition dump = forbidden.

Shock / pressure → shorter speech, no fluent self-analysis.

Speaker clear → omit speech verb.

Incomplete phrase allowed iff interruption is diegetic + visible.

## Figurative Language

Metaphor / simile = sparse, concrete. Max #2 per paragraph.

Character's frame of reference determines available comparisons.

Physical detail already carries meaning → cut comparison.

## Narration Discipline

Narration may state: physical fact / sensory fact / body response / environmental change / immediate thought.

Narration must not: declare meaning / explain emotion / interpret action / judge significance.

## Closing Beat

End on forward movement: body / object / environment / unfinished action / sensory shift / arrival / interruption / immediate thought.

Do not end on: lesson / emotional explanation / resolved summary / rhetorical question / direct prompt.

## Sentence-Level Prohibitions

### Hollow Fragment Chains

Stacking 2+ short declarative sentences that each add no new information = forbidden.

Bad:

- Description: 국물을 마셨다. 미지근했다. 순대 냄새가 났다. 마셨다.

Good:

- Description: 미지근한 국물에서 순대 냄새가 올라왔지만 그대로 들이켰다.

### Nominalized Commentary

~는 거 / ~는 것 / ~는 셈 as narrator editorial = forbidden.

Bad:

- Description: 이미 앉아놓고 묻는 거.

Good:

- Description: 이미 앉아 있었다. 그러고선 질문이 튀어나왔다.

### Explanatory Pre-framing

Narrator qualifying own narration before the action = forbidden.

Bad:

- Description: 내가 무슨 말을 한 건지 모르겠는데 유나가 웃었다.

Good:

- Description: 유나는 숟가락을 입에 문 채로 *푸흡* 하고 웃었다.

### False-Gravity Assertions

Blunt declarative fragments that manufacture weight = forbidden.

Bad:

- Description: 끝. 그게 전부다.

### Indirect-Speech Echo

Reporting speech, then restating its truth value = forbidden.

Bad:

- Description: 괜찮다고 했다. 괜찮았다. 진짜로.

Good:

- Dialogue: "괜찮아."
- Description: 유나는 고개를 끄덕이고는 다음 숟가락을 떴다.

### Standalone Time Fragment

Time as isolated sentence for dramatic pacing = forbidden. Embed in sentence.

Bad:

- Description: 11시 52분.

Good:

- Description: 11시 52분이 되어서야 답장이 도착했다.

### Noun-List Sentence

Action sequence as comma-separated noun list = forbidden. Use verb-form connected prose.

Bad:

- Description: 복사, 붙여넣기, 폰트 통일, 출처 달기.

Good:

- Description: 복사하고, 붙여넣는다. 폰트도 맞추고, 출처도 단다.
